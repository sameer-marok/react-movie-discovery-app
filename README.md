# My First React App

A React application built with Vite as a starting point for learning React fundamentals.

## Getting Started

### 1. Install Dependencies

Install the required packages:

```bash
npm install
```

### 2. Run the Development Server

Start the app locally:

```bash
npm run dev
```

The app is typically available at [http://localhost:5173](http://localhost:5173).

## Project Structure

- `src/` - React components and application logic.
- `public/` - Static assets, such as images and icons.
- `index.html` - The application entry point.
- `package.json` - Project metadata and npm scripts.

## Deployment

Generate an optimized production build:

```bash
npm run build
```

The generated files will be placed in the `dist/` folder, ready for deployment.
